# CodeMax Internship - Module 2

## Python Mini Project - Student Grade Calculator

This project is a beginner-friendly Python program that calculates a student's total marks, percentage and grade based on marks entered for three subjects.

## Features

- Takes student name as input
- Takes marks for three subjects
- Calculates total marks
- Calculates percentage
- Assigns grade based on percentage

## Grading System

- 75 and above: A
- 60 to 74.99: B
- 50 to 59.99: C
- 40 to 49.99: D
- Below 40: F

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Open a terminal in the project folder.
3. Run:

python student_grade_calculator.py

## Learning Outcome

This project helped me practice Python input/output, variables, arithmetic operations and conditional statements.
